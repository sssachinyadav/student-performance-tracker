# Problem Statement
Managing and tracking student academic performance manually or via scattered spreadsheets is inefficient and prone to errors. This project provides a centralized, console-based Java system to store student marks, calculate grades, and manage records smoothly.

# Scope of Project
- Store student details, scores, and calculate average grades.
- Export performance reports directly into a CSV file format.
- Handle basic CRUD operations for student records.

# Target Users
- Teachers, school administrators, and academic evaluators.

# Key Features
- Add student records and assign marks.
- Automatic grade calculation and average scoring.
- Export student reports to standard `.csv` files for record-keeping.
